# BABEL — Prototype 8 vocabulary upgrade

The website currently functions on a generated word sheet from the Princeton WordNet. WordNet provides the vocabulary, but the categories are based on selected semantic domains and curated rules, not a mathematically precise measurement of distance from Babel.

**The current generated word sheet is smaller than the actual word count of WordNet, but it includes generous number of words nonetheless**

**The exclusion process is approximate** words are filtered from the biblical passage and Babel-related concepts, but cannot guarantee that every possible semantic association has been eliminated.
